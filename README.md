# LuxeMotor: Curated Automotive Excellence

A premium car-dealership site with an animated landing page, a showroom and individual vehicle pages.

**Live demo:** https://luxemotor.vercel.app

## Features
- Animated landing page built with GSAP
- Showroom page for browsing the collection
- Dynamic vehicle detail pages (`/vehicles/[slug]`)
- Responsive UI with shadcn components, plus Vercel Analytics

## Tech stack
Next.js (App Router), React 19, TypeScript, Tailwind CSS, shadcn/ui, GSAP, Lucide icons.

## Getting started
```bash
pnpm install
pnpm dev
```
